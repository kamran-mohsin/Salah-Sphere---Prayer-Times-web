# 🕌 Salah Sphere - Prayer Times Web

A comprehensive and modern Islamic web application designed to help you stay on track with your daily prayers and Islamic routines.

## ✨ Features Included

- **⏱️ Prayer Times:** Get accurate daily Namaz timings.
- **🧭 Qibla Direction:** Easily find the exact direction for your prayers.
- **🌙 Fasting Tracker:** Keep a record of your daily fasting.
- **🤲 Islamic Duas:** A collection of essential daily supplications.
- **🗓️ Qadha Tracker:** Keep track of your missed (Qadha) prayers to fulfill them later.
- **✅ Daily Activities:** Manage your daily Islamic activities and routines.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript (Vanilla)
- **Icons & Graphics:** Custom SVGs and clean UI design
